# KaziScout brand

"Kazi" is Swahili for work. The mark is a K whose arm is a compass needle: a scout pointing the
way to work.

| Asset | File       | Use                        |
| ----- | ---------- | -------------------------- |
| Mark  | `mark.svg` | App icon, favicon, avatars |
| Logo  | `logo.svg` | README header, documents   |

## Colours

| Role    | Hex       | Use                                             |
| ------- | --------- | ----------------------------------------------- |
| Forest  | `#0f3d2e` | Brand surfaces: sidebar, mark background        |
| Leaf    | `#14694b` | Primary actions and links                       |
| Savanna | `#e8a13a` | Accent: the needle, highlights on dark surfaces |
| Ochre   | `#c47f17` | Savanna for text on light backgrounds           |
| Paper   | `#f6f5f1` | Page background                                 |

The same values are defined once as design tokens in `web/src/styles/tokens.css`; components
never use raw colour values.

## Voice

Plain and specific. Say what a button does ("Scan all boards", not "Go"). Never promise a job;
KaziScout finds and ranks postings, and the person applies.
